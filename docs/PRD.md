## 1. 서비스 개요 및 목적

### 1.1 서비스 개요
**마이링크(MyLink)**는 개인 크리에이터, 프리랜서, 일반 사용자가 인스타그램, 틱톡, 유튜브, 블로그, 포트폴리오 등 분산되어 있는 여러 링크를 단 하나의 모바일 친화적인 프로필 페이지로 모아서 공유할 수 있는 **링크트리(Linktree) 클론 서비스**입니다.

### 1.2 개발 및 서비스 목적
1. **단일 URL 기반 연결 허브**: SNS 프로필에 등록할 수 있는 링크 개수 제한(예: 인스타그램 프로필 1개 링크 제한)을 극복하고, 사용자의 모든 디지털 채널을 단 하나의 랜딩 페이지로 통합 제공.
2. **별도 서버 구축 없는 즉시 사용성**: 복잡한 백엔드 설정이나 데이터베이스 의존성 없이, Next.js 클라이언트 환경에서 `localStorage`와 기본 예시 데이터를 활용하여 브라우저에서 즉각 구동 및 체험 가능한 완성도 높은 독립형 데모 제공.
3. **직관적인 관리 및 라이브 피드백**: 드래그 앤 드롭을 통한 손쉬운 링크 순서 변경과 데스크톱 관리 화면에서 모바일 뷰를 실시간으로 확인할 수 있는 라이브 프리뷰(Live Preview) 환경 제공.
4. **TDS 기반의 완성도 높은 비주얼**: `design.md`에 명시된 토스 디자인 시스템(TDS) 스타일(Pretendard 폰트, Canonical Blue, 세련된 그레이스케일, 일관된 라운딩 및 간격)을 적용하여 신뢰도 높은 감성 디자인 제공.

## 2. 타깃 사용자 및 핵심 가치

### 2.1 타깃 사용자
- **SNS 인플루언서 및 크리에이터**: 유튜브, 인스타그램, 틱톡, 팟캐스트 등 다채널 링크를 팬들에게 한 번에 전달해야 하는 사용자.
- **프리랜서 및 구직자**: 노션 이력서, 깃허브, 비핸스 포트폴리오, 문의 링크를 정돈된 명함 형태로 공유하려는 사용자.
- **일반 사용자**: 일상 블로그, 개인 프로젝트, 오픈채팅방 링크를 간편하게 묶어 전달하고 싶은 사용자.

### 2.2 핵심 가치 (Core Value)
- **Zero-Barrier Setup**: 회원가입/서버 승인 절차 없이 기본 제공되는 예시 데이터와 함께 바로 편집 시작 가능.
- **WYSIWYG(보는 대로 완성되는) 경험**: 관리자가 링크를 켜고 끄거나 텍스트를 수정하면 우측 모바일 프리뷰에 1:1 실시간 반영.
- **심미성 및 다양성**: 토스 디자인 시스템 기반의 정갈한 기본 UI 및 감각적인 테마 프리셋 제공.
- **성과 측정(Insights)**: 방문자와 링크 클릭 수, 최근 7일 추이를 즉각 파악할 수 있는 내장 통계 차트.

## 4. 데이터 스키마 및 저장소 명세 (`localStorage`)

별도의 백엔드 데이터베이스 없이 브라우저 `localStorage`를 메인 영속성 레이어로 사용하며, 최초 진입 시 데이터가 비어 있을 경우 풍부한 **기본 예시(Seed Mock) 데이터**를 자동 주입합니다.

### 4.1 스토리지 키 규격
- `mylink_profile_data`: 프로필 정보 및 소셜 배지
- `mylink_links_data`: 등록된 링크 및 블록 목록 (순서 배열)
- `mylink_theme_data`: 선택된 테마 프리셋 및 커스텀 스타일 설정
- `mylink_analytics_data`: 페이지 뷰, 링크별 클릭 수, 일자별 추이 로그

### 4.2 TypeScript 인터페이스 정의

```typescript
// 1. 프로필 정보
export interface ProfileData {
  username: string;          // 고유 닉네임/핸들 (예: "creator_kim")
  displayName: string;       // 화면 표시 이름 (예: "김링크 | Tech Creator")
  bio: string;               // 자기소개 문구
  avatarUrl: string;         // 프로필 사진 URL (기본 제공 아바타 또는 이미지 URL)
  socials: SocialBadge[];    // 소셜 미디어 배지 목록
}

// 2. 소셜 미디어 배지
export interface SocialBadge {
  id: string;
  platform: 'instagram' | 'youtube' | 'x' | 'tiktok' | 'github' | 'blog' | 'email';
  url: string;
  enabled: boolean;
}

// 3. 링크 및 블록 아이템
export type BlockType = 'link' | 'header';

export interface LinkItem {
  id: string;
  type: BlockType;           // 'link'(일반 버튼 링크) 또는 'header'(섹션 구분 제목)
  title: string;             // 링크 텍스트 또는 헤더 명칭
  url?: string;              // 링크 대상 URL (header 타입일 경우 선택)
  iconName?: string;         // Lucide 아이콘 명 또는 이모지
  enabled: boolean;          // 링크 활성화/비활성화 (On/Off 토글)
  clicks: number;            // 해당 링크 누적 클릭 횟수
  order: number;             // 정렬 순서 index
}

// 4. 테마 설정
export type ThemePreset = 'toss-blue' | 'dark-minimal' | 'pastel-cream' | 'modern-charcoal';

export interface ThemeConfig {
  preset: ThemePreset;
  customBackgroundColor?: string;
  buttonShape: 'rounded' | 'pill' | 'square';  // 모서리 둥글기 (12px, 9999px, 0px)
  buttonVariant: 'filled' | 'outline' | 'soft'; // 버튼 채움 스타일
}

// 5. 통계 및 로그
export interface DailyStat {
  date: string;              // "YYYY-MM-DD"
  views: number;             // 해당 일자 총 방문수
  clicks: number;            // 해당 일자 총 링크 클릭수
}

export interface AnalyticsData {
  totalViews: number;        // 누적 총 방문자 수
  totalClicks: number;       // 누적 총 링크 클릭 수
  dailyStats: DailyStat[];   // 최근 7~30일 추이 배열
}
```

## 5. 핵심 기능별 상세 요구사항

---

### 5.1 공개 프로필 뷰 (Public Profile Page)

방문자가 접속했을 때 링크들을 탐색하고 원하는 목적지로 이동할 수 있는 최종 랜딩 화면입니다.

1. **프로필 헤더**
   - **프로필 사진 (Avatar)**: 정원형(Circular) 썸네일, 이미지 로드 실패 시 이니셜 대체 표시.
   - **이름 (Display Name)**: `design.md`의 `h2` 또는 `h3` 스케일 타이포그래피 적용, 굵고 또렷한 텍스트.
   - **자기소개 (Bio)**: 최대 2~3줄 줄바꿈 지원, 부드러운 보조 색상(`grey-700` / `grey-600`) 텍스트.
2. **소셜 미디어 배지 바 (Social Badges)**
   - 등록된 활성 소셜 플랫폼(Instagram, YouTube, X, GitHub, TikTok 등) 아이콘을 가로 일렬(Row) 배치.
   - 아이콘 클릭 시 해당 외부 URL로 `target="_blank"` 새 창 열림.
   - 마우스 호버 및 모바일 터치 시 미세한 스케일 애니메이션(`scale-110`, transition 150ms).
3. **섹션 구분 제목 (Header Block)**
   - 링크들을 그룹화할 수 있는 소제목 텍스트 블록.
   - 상단 링크 목록과 하단 링크 목록 사이에 시각적 분리선(Divider) 및 섹션 타이틀 역할.
4. **링크 버튼 목록 (Link Buttons)**
   - 관리자가 설정한 순서대로 세로 리스트 형태로 나열.
   - 버튼 구성:
     - 좌측: 썸네일 또는 아이콘(Lucide React 아이콘 지원).
     - 중앙: 링크 제목(Title).
     - 우측: 외부 링크 화살표 아이콘(ChevronRight 또는 ExternalLink).
   - 비활성화(`enabled: false`)된 링크는 방문자 페이지에서 렌더링되지 않음.
   - **클릭 이벤트 핸들링**:
     - 링크 버튼을 탭하면 `localStorage`의 `clicks` 수 및 당일 통계(`dailyStats.clicks`)를 즉시 1 증가시키고 대상 URL을 새 탭에서 호출.
5. **하단 푸터 (Footer)**
   - "Made with MyLink" 브랜딩 텍스트 및 기본 로고 배치.

#### 5.1.1 사용자 시나리오 — 방문자와 소유자

**방문자 · 현재 시연**

1. 사용자는 다른 사람의 프로필을 보기 위해 SNS 게시물이나 메시지에서 공유받은 마이링크 주소를 연다. 시연에서는 공개 프로필 `/`에 접속한다.
2. 사용자는 누구의 페이지인지 확인하기 위해 프로필 상단의 이름, 소개, 아바타와 소셜 배지를 살펴본다.
3. 사용자는 관심 있는 콘텐츠를 찾기 위해 ‘링크’ 탭에서 링크 제목을 읽는다. 기본 화면에서는 ‘개인 포트폴리오’나 ‘기술 블로그’를 찾을 수 있다.
4. 사용자는 원하는 콘텐츠를 열기 위해 해당 외부 링크를 누르고, 새 탭에 열린 목적지 페이지를 확인한다.

현재 화면에는 접속한 브라우저의 `localStorage` 값이 반영된다.

| 데이터 | 유효한 저장값이 있을 때 | 저장값이 없을 때 |
| :--- | :--- | :--- |
| 프로필 (`mylink_profile_data`) | 저장된 이름, 소개, 아바타, 활성 소셜 배지를 표시한다. 아바타를 불러올 수 없으면 이름의 첫 글자를 표시한다. | 김태경의 기본 프로필을 표시한다. |
| 링크 (`mylink_links_data`) | 활성 링크와 구분 제목을 저장된 순서대로 표시한다. 빈 배열이면 ‘등록된 링크가 없어요’를 표시한다. | ‘개인 포트폴리오’, ‘기술 블로그’ 등 예시 링크를 표시한다. |

두 키는 각각 기본값을 적용한다. 프로필만 저장되어 있으면 저장된 프로필과 예시 링크가 함께 표시된다. 주소를 공유해도 공유자의 브라우저에 저장된 데이터는 전달되지 않으므로, 저장값이 없는 브라우저에서 접속한 방문자는 기본 화면을 본다. 다른 기기에서도 소유자가 게시한 내용을 보여 주는 공개 주소와 방문·클릭 집계는 후속 구현 범위다.

**소유자 · 현재 시연**

1. 사용자는 자신의 프로필과 링크가 어떻게 보이는지 확인하기 위해 공개 프로필을 열어 이름, 소개, 소셜 배지와 링크 목록을 살펴본다.
2. 사용자는 프로필 주소를 공유하기 위해 상단의 ‘링크 복사하기’를 누르고 복사한 주소를 SNS 게시물이나 프로필에 직접 붙여 넣는다. 로컬 시연의 `localhost` 주소는 시연 기기에서 열 수 있다.

**소유자 · 링크 관리 (후속 구현)**

1. 사용자는 자신의 공개 프로필에 표시할 링크를 관리하기 위해 관리 대시보드를 열고 ‘링크 관리’로 이동한다.
2. 사용자는 새 링크를 등록하기 위해 ‘일반 링크 추가’를 선택하고 링크 제목과 대상 URL을 입력해 저장한다.
3. 사용자는 등록 결과를 확인하기 위해 링크 목록과 미리보기에서 새 링크의 제목과 목적지를 확인한다.
4. 사용자는 제목이나 목적지가 바뀐 링크를 갱신하기 위해 목록에서 해당 항목을 찾아 제목 또는 URL을 수정하고 저장한다.
5. 사용자는 더 이상 필요 없는 링크를 목록에서 제거하기 위해 대상 항목의 ‘삭제’를 선택하고 미리보기에서 해당 링크가 사라졌는지 확인한다.

### 5.2 관리 대시보드 (Admin Dashboard)

소유자가 프로필 정보, 링크 목록, 테마 설정을 한 화면에서 유기적으로 조작하는 핵심 작업 공간입니다.

1. **2단 분할 레이아웃 (Split-Screen Editor)**
   - **좌측 (편집 패널)**: 탭 메뉴(프로필 편집, 링크 관리, 테마 설정, 통계 분석)와 폼 컨트롤.
   - **우측 (모바일 실시간 미리보기)**: 스마트폰 외곽선(Phone Mockup Frame) 형태의 뷰포트에 현재 편집 중인 프로필 페이지를 실시간 렌더링.
   - 반응형 지원: 태블릿/모바일 접속 시에는 탭 전환 또는 하단 시트/플로팅 버튼으로 미리보기 토글 지원.
2. **프로필 및 소셜 미디어 편집**
   - 아바타 이미지 URL 입력 (또는 사전 제공 아바타 프리셋 선택기).
   - 표시 이름, 한 줄 소개(Bio) 실시간 인풋 입력 및 유효성 검사.
   - 소셜 미디어 링크 입력 필드 (각 플랫폼별 URL 입력 및 On/Off 토글).
3. **링크 및 블록 관리**
   - **신규 블록 추가**:
     - "일반 링크 추가": 제목, 대상 URL, 아이콘 선택.
     - "구분 헤더 추가": 섹션 제목 텍스트 입력.
   - **드래그 앤 드롭 (Drag & Drop) 순서 변경**:
     - 링크 카드 좌측의 드래그 핸들(`GripVertical` 아이콘)을 잡고 끌어서 위아래로 손쉽게 순서 재배열.
     - 순서 변경 시 즉시 `localStorage`에 `order` 순서 반영 및 우측 모바일 프리뷰 자동 갱신.
   - **인라인 편집 (Inline Edit)**: 카드 내에서 제목과 URL을 바로 수정 가능.
   - **활성화 토글 (Switch)**: 삭제하지 않고 임시로 숨길 수 있는 활성/비활성 스위치.
   - **삭제 (Delete)**: 확인 모달 또는 즉시 제거 기능.
4. **데이터 초기화 & 리셋 버튼**
   - 사용자가 언제든지 테스트 상태를 깨끗한 초기 기본 예시 상태로 복원할 수 있는 "예시 데이터 복원" 기능 제공.

### 5.4 통계 및 성과 분석 (Analytics Dashboard)

사용자가 자신의 프로필 링크가 얼마나 많은 성과를 내고 있는지 파악할 수 있는 통계 뷰입니다.

1. **주요 지표 요약 카드 (Summary KPI Cards)**
   - **총 방문자 수 (Total Views)**: 공개 프로필 페이지에 접근한 누적 횟수.
   - **총 링크 클릭 수 (Total Clicks)**: 전체 링크 버튼이 클릭된 총합.
   - **전체 클릭률 (Average CTR)**: `(총 클릭 수 / 총 방문자 수) * 100` (%) 자동 계산.
2. **최근 7일 추이 차트 (Trend Chart)**
   - 최근 7일간의 일자별 방문자 수와 링크 클릭 수를 비교할 수 있는 시각적 막대/선 차트.
   - 라이브러리 추가 없이 SVG 또는 Tailwind 기반 반응형 Bar Chart로 가볍고 명확하게 렌더링.
3. **개별 링크별 클릭 성과 랭킹 테이블**
   - 등록된 링크별 누적 클릭 수 및 점유율(%) 프로그레스 바 표시.
   - 가장 성과가 좋은 'Best Link' 뱃지 하이라이트.
4. **테스트 및 초기화 도구**
   - "테스트 방문 카운트 +1", "통계 데이터 초기화" 버튼을 제공하여 개발 및 시연 시 원활한 기능 검증 지원.

## 7. 비기능적 요구사항 및 제약사항

1. **반응형 웹 및 모바일 퍼스트 (Mobile-First)**:
   - 공개 프로필 페이지는 모바일 화면 폭(최대 `max-w-md`, 440px)을 기본 캔버스로 하여 인스타그램 인앱 브라우저 및 스마트폰 웹 환경에 완벽 최적화.
   - 관리 대시보드는 태블릿 및 데스크톱 폭(`lg: 1024px 이상`)에서 2열 분할 뷰로 동작.
2. **LocalStorage 무결성 및 예외 처리**:
   - 브라우저 시크릿 모드나 쿠키/스토리지 차단 환경에서도 앱이 충돌하지 않도록 `try-catch` 방어 코드 적용.
   - 잘못된 JSON 포맷이 감지되거나 스토리지 키가 손상되었을 경우 기본 Mock 데이터로 자동 Fallback.
3. **접근성 및 인터랙션 피드백**:
   - 모든 버튼과 인터랙션 요소는 터치 가능한 최소 44x44px 크기 확보.
   - 링크 복사(공유) 시 토스트(Toast) 알림을 띄워 사용자에게 완료 상태 피드백 제공.
4. **외부 종속성 최소화**:
   - 별도 외부 백엔드 서버(Node.js API, DB, 인증 서버) 호출 없이 완전히 독립적으로 빌드(`next build`) 및 정적 배포(Vercel, GitHub Pages 등) 가능한 구조 유지.

## 8. 릴리즈 체크리스트 및 성공 지표

### 8.1 릴리즈 체크리스트 (MVP 완료 기준)
- [ ] 브라우저 최초 접속 시 기본 예시 프로필/링크가 정상적으로 화면에 노출되는가?
- [ ] 프로필 이름, 사진, 소개 변경 시 실시간 모바일 미리보기에 즉시 반영되는가?
- [ ] 링크 추가, 수정, 삭제 및 활성화/비활성화 토글이 정상 작동하는가?
- [ ] 링크 목록을 드래그하여 순서를 바꿀 수 있고, 순서가 localStorage에 저장되는가?
- [ ] 4종의 프리셋 테마를 변경했을 때 프로필 스타일에 즉각 반영되는가?
- [ ] 링크 버튼 클릭 시 새 창으로 연결되며, 통계 수치(클릭 수)가 1 증가하는가?
- [ ] 최근 7일 추이 차트에 일별 방문 및 클릭 데이터가 시각화되는가?
- [ ] '예시 데이터 초기화' 기능으로 초기 상태 복구가 원활한가?

### 8.2 성공 지표 (Success Metrics)
- **Time to First Edit**: 사용자가 첫 진입 후 자신의 링크 1개를 추가/수정하는 데 걸리는 시간 1분 이내.
- **Zero Console Errors**: 브라우저 콘솔에 하이드레이션 불일치나 런타임 에러 0건 유지.
